## ONNX 结构对比（Netron + 代码双重验证）

| 项 | YOLOv8n | YOLO26n |
|---|---|---|
| 文件大小 | 12.2 MB | 9.4 MB（−23%） |
| 节点数 | 234 | 368 |
| MatMul / attn 节点 | 0 / 0 | 4 / 28 |
| Softmax | 1（DFL） | 2（均为 attention） |
| 输入 / 输出 | images[1,3,640,640] / output0[1,5,8400] | **完全相同** |

三条结论：
1. **26n 在 backbone 末端（model.10）和 head 之前（model.22）各插入一个
   self-attention 块**（2 MatMul + 1 Softmax，qkv 由卷积生成），v8 是纯卷积。
2. **26n 没有 DFL 的 Softmax 路径**，框坐标直接回归 —— 与官方"去 DFL"一致。
3. **两代 ONNX 的输入输出契约完全一致**，所以推理后处理可以复用同一套代码。
